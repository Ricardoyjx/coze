# 招聘助手 AI Agent - 功能汇报文档

## 项目概述

招聘助手是一个基于 Coze Bot + FastAPI + React 的智能招聘平台，整合了 JD 生成、简历审查、面试题生成、Offer 邮件、薪资分析等核心招聘流程，通过 AI 自动化提升招聘效率。

## 技术架构

- **前端**: React + TypeScript + Ant Design + Vite
- **后端**: Python FastAPI + Uvicorn
- **AI 引擎**: Coze Bot (多 Space 多 Bot 架构)
- **通信协议**: SSE (Server-Sent Events) 流式响应

---

## 功能模块

### 1. JD 智能生成

**入口**: 侧边栏「JD生成」

**功能描述**: 输入岗位名称、职责要求、薪资范围等信息，AI 自动生成专业的招聘 JD 文档。

**技术实现**:
- 调用 `jd_generator` Coze Bot，流式返回生成结果
- 前端实时展示生成过程，支持 Markdown 渲染
- 生成结果包含：岗位职责、任职要求、加分项、薪资福利

**API 接口**: `POST /api/jd/generate` (SSE 流式)

---

### 2. 简历初筛

**入口**: 侧边栏「简历初筛」

**功能描述**: 上传简历文件 + 粘贴 JD 内容，AI 自动解析简历、评分并排序推荐候选人。

**技术实现**:
- 支持 PDF、Word 格式批量上传
- 后端提取简历文本内容（pypdf / python-docx）
- 调用 `resume_screening` Coze Bot 逐份分析
- **真实性核查**: 检测造假行为，核查毕业年份与工作年限是否匹配
- 流式返回进度和结果，前端展示奥特曼打怪兽动画

**核心字段**:
- `score`: 匹配得分 (0-100)
- `recommendation`: 推荐等级 (strong/moderate/weak)
- `matchPoints`: 匹配点列表
- `missingPoints`: 缺失项列表
- `integrityIssues`: 真实性问题列表
- `integrityScore`: 可信度评分
- `timelineConsistent`: 时间线是否一致

**API 接口**:
- `POST /api/resume/upload` - 上传简历文件
- `POST /api/resume/screening/run` - 执行初筛 (SSE 流式)
- `GET /api/resume/{resume_id}/file` - 下载简历文件

---

### 3. 面试题生成

**入口**: 侧边栏「面试题」

**功能描述**: 输入岗位名称和 JD 内容，AI 自动生成面试题，包含题目、考察点和参考答案。

**技术实现**:
- 调用 `interview_questions` Coze Bot，流式返回
- 支持选择题目类型（技术题、行为题、情景题等）
- 支持选择难度（简单、中等、困难）
- 支持选择生成数量（1-5 题）

**API 接口**: `POST /api/interview-questions/generate` (SSE 流式)

---

### 4. 简历审查（批量筛选）

**入口**: 侧边栏「简历审查」

**功能描述**: 批量上传简历文件，AI 自动解析、评分、核查真实性，高效筛选候选人。

**技术实现**:
- 支持 PDF、Word 格式批量上传
- 调用 `batch_screening` Coze Bot 逐份分析
- **真实性核查**: 检测造假行为，核查毕业年份与工作年限是否匹配
- SSE 流式返回进度，前端展示奥特曼动画
- 结果支持按分数、可信度排序
- 支持按通过/未通过/存疑筛选
- 支持导出 CSV 报告

**核心字段**:
- `score`: 匹配得分
- `recommendation`: 推荐等级
- `mainTech`: 主技术栈
- `skills`: 技能列表
- `integrityIssues`: 真实性问题
- `integrityScore`: 可信度评分
- `timelineConsistent`: 时间线是否一致

**API 接口**:
- `POST /api/batch-screen` - 批量审查 (SSE 流式)

---

### 5. Offer 邮件生成

**入口**: 侧边栏「Offer邮件」

**功能描述**: 填写候选人信息，AI 自动生成正式的 Offer 录用通知书。

**技术实现**:
- 调用 `offer_email` Coze Bot，流式返回
- 表单包含：候选人姓名、录用岗位（下拉选择）、薪资待遇、报到日期（带日期校验）、工作地点、备注
- 生成结果包含：录用详情、入职材料、薪酬福利、确认方式

**岗位预设选项**:
- 高级Java开发工程师
- 前端开发工程师
- 产品经理
- 数据分析师
- 算法工程师
- UI/UX设计师

**API 接口**: `POST /api/offer-email/generate` (SSE 流式)

---

### 6. 薪资分析

**入口**: 侧边栏「薪资分析」

**功能描述**: 输入岗位信息，基于市场数据提供合理薪资建议和行业对比分析。

**技术实现**:
- 调用 `salary_analysis` Coze Bot，返回 JSON 结果
- 包含薪资分位数（P10-P90）、行业对比、城市对比
- 经验 vs 薪资、学历 vs 薪资对比图表
- 支持选择城市、工作经验、学历

**核心数据**:
- `salaryRange`: 薪资范围 (min/max/median)
- `percentiles`: 分位数 (P10/P25/P50/P75/P90)
- `industryAvg`: 行业平均薪资
- `cityAvg`: 城市平均薪资
- `experienceLevels`: 经验 vs 薪资
- `educationImpact`: 学历 vs 薪资
- `recommendedRange`: 建议薪资范围
- `confidence`: 数据可信度

**API 接口**: `POST /api/salary/analyze`

---

### 7. Coze Bot 配置管理

**入口**: 侧边栏底部「Coze配置」

**功能描述**: 管理 Coze Bot 的 API Key、Bot ID 等配置信息。

**技术实现**:
- 从 `.env` 文件读取多 Space 配置
- 支持查看各 Bot 的连接状态
- 支持切换不同的 Bot

**已配置的 Bot**:
- `jd_generator`: JD生成 (by 伍仪永)
- `resume_screening`: 简历初筛评分 (by 陈海/曹鹏飞)

## 特色功能

1. **SSE 流式响应**: 所有 AI 生成类功能均支持流式返回，实时展示生成过程
2. **真实性核查**: 简历初筛和审查功能自动检测造假行为，核查时间线一致性
3. **多 Bot 架构**: 支持多个 Coze Bot 独立配置，按需调用
4. **奥特曼动画**: 处理中的加载动画，提升用户体验
5. **CSV 导出**: 简历审查结果支持导出 CSV 报告
6. **RFC 5987 文件下载**: 支持中文文件名的简历文件下载
